# 文言虚词 · 义项训练

在线地址：**https://maxnight988-gif.github.io/wenyan/**

一个单页、离线可用的文言虚词训练页。手机、平板、电脑都能直接打开，不用登录、不收集任何数据（学习进度只存在你自己的浏览器里）。

## 装到 iPhone 上（推荐）

1. 用 **Safari** 打开上面的网址（微信/QQ 内置浏览器不行）
2. 点底部「分享」→ **添加到主屏幕** → 添加
3. 主屏幕上会出现「文言虚词」图标；以后直接从图标打开

打开后全屏、没有地址栏，和原生 App 一样；Service Worker 会把页面缓存下来，**断网也能刷题**。联网打开时会自动取最新版。

安卓同理：Chrome 菜单 →「添加到主屏幕 / 安装应用」。

## 两种模式

- **义项训练** —— 18 个虚词、64 个义项、127 条例句。同一个「之」的不同用法是不同卡片，选项全部来自同一个字，专门制造真实混淆。
- **句式判断** —— 36 个句子，覆盖判断、被动、宾语前置、定语后置、状语后置、省略、固定句式七类。答完给标志、还原、译文，以及"判断出来之后翻译/断句时要做什么"。

## 三种题型

| 题型 | 占比 | 考什么 |
|---|---|---|
| 正向 | 约 43% | 给例句，选义项 |
| 反向 | 约 35% | 给义项，选例句（防止只记住卡片长相） |
| 填空 | 约 22% | 挖掉目标字，自己写义项 |

答错的卡 10 分钟后重新到期，下一组优先出现；答对按 1 / 3 / 7 / 16 / 35 / 75 天递进。

首页可以切换「全部」和「只考高中篇目」：后者只出有高中例句的义项，且题干、选项、反馈里的例句全部来自高中篇目。

## 进度

进度存在浏览器 localStorage，换浏览器/清缓存会丢。页脚有「导出进度 / 导入进度」，换设备时带上 JSON 文件即可。

## 更新这个页面

页面主体就是根目录的 `index.html`：

1. 改好本地文件，覆盖 `index.html`
2. `git commit -m "..."` + `git push`
3. 约一分钟后 GitHub Pages 自动重建，刷新网址即可（离线缓存是"网络优先"，联网打开就是新版）

`manifest.json` 提供应用名/主题色/图标信息，`sw.js` 负责离线缓存，`icons/` 是主屏幕图标。这三样只在改名字、换图标时才需要动。

没有构建步骤、没有依赖、没有后端。

## 语料

例句全部来自高中与初中课本里的文言篇目（劝学、师说、鸿门宴、赤壁赋、六国论、过秦论、烛之武退秦师、曹刿论战、桃花源记……），每句都配白话译文。
